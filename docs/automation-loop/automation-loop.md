# Alpine Wave — Autonomous Multi-Agent Automation Loop

The Alpine Wave automation loop runs software delivery across a 5-stage verification board (Draft, Todo, Building, Review, Done). Every task is tracked on an explicit job card specifying boundaries, requirements, and verification criteria. Autonomous agents pick tickets, build in dedicated branches, and submit work to independent gatekeepers. Automated quality checks catch defects early and rebound cards for rework, while repeated failures escalate to the owner for steering.
